# Homebrew Tap

Homebrew formulae for [tijs](https://github.com/tijs) projects.

## Install

```bash
brew tap tijs/tap
brew install attic
```

Or directly:

```bash
brew install tijs/tap/attic
```

## Formulae

| Formula | Description |
|---------|-------------|
| [attic](https://github.com/tijs/attic) | Back up your iCloud Photos library to S3-compatible storage |
