# Homebrew Tap

Homebrew formulae and casks for [tijs](https://github.com/tijs) projects.

## Install

```bash
brew tap tijs/tap
brew install attic
brew install --cask peel
```

Or directly:

```bash
brew install tijs/tap/attic
brew install --cask tijs/tap/peel
```

## Formulae

| Formula | Description |
|---------|-------------|
| [attic](https://github.com/tijs/attic) | Back up your iCloud Photos library to S3-compatible storage |

## Casks

| Cask | Description |
|------|-------------|
| [peel](https://github.com/tijs/Peel) | Native macOS app for removing image backgrounds |
